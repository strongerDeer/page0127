# 공개 오픈 점검 — 설계

> 작성 2026-08-06 · 대상 `page0127` (운영 `https://page0127.com`)
> 범위: **검색 유입을 기대하는 공개 오픈**. 지인 베타가 아니라 모르는 사람이 들어오는 상태를 전제한다.

---

## 0. 이 문서를 쓰는 이유

오픈 전 운영 검증(백업 복원·uptime·Sentry·전체 시나리오)은 2026-07-29에 이미 끝났다
(`00_docs/00_남은_작업_목록.md` 2순위). **기능이 도는지는 확인됐다.**

남은 것은 성격이 다르다 — **처음 온 사람이 보는 첫인상**과 **법적 고지**다.
링크를 눌렀을 때 뜨는 그림, 탭에 뜨는 아이콘, 검색에 잡히는지, 수집하는 정보를 제대로 밝혔는지.
기능 점검이 아니라서 지금까지 목록에 없었다.

## 2. 우선순위

### P0 — 오픈 전에 반드시

**법적 고지와 첫인상.** 이게 안 된 채로 열면 되돌리기 어렵다 —
공유된 링크의 미리보기 이미지는 각 플랫폼에 캐시되고, 개인정보 고지 누락은 법적 문제다.

| 항목 | 지금 | 해야 할 것 |
| --- | --- | --- |
| **P0-1 개인정보처리방침에 카카오** | 구글만 적혀 있음 | 수집 항목에 카카오 추가. **이메일이 없을 수 있다**는 점도 명시(카카오는 이메일 동의가 선택) |
| **P0-2 파비콘** | 녹색 `#2f5d3a` | `brand/symbol-bg` 기반 블루로 교체 + `apple-icon` 신설 + `manifest` 신설 |
| **P0-3 OG 3종** | 스카이 배경·좌측 정렬·앰버/오렌지 섞임 | 흰 배경·가운데 정렬·블루 통일. 서브 카피 교체 |
| **P0-4 배너 카피** | "2026년 하반기" 박제 | 날짜 표현 제거 또는 자동 계산 |
| **P0-5 미사용 이미지** | 7.5MB가 배포에 실림 | 쓰는 것만 남기고 저장소 밖으로 |

**P0-1은 카카오 로그인 병합과 같은 PR이어야 한다.** 기능이 먼저 나가고 고지가 나중에 가면
그 사이에 가입한 사람에게는 고지 없이 정보를 받은 것이 된다.

## 3. 하지 않기로 한 것

범위를 넓히지 않기 위해 명시한다.

| 뺀 것 | 이유 |
| --- | --- |
| PWA·웹푸시 | 신규 구축이 필요하고 iOS 도달률이 낮다. manifest는 **아이콘·이름 때문에** 넣는 것이지 PWA를 하려는 게 아니다 |
| 마스코트 자산 적용 | 로고 계열(네이비·코랄)과 마스코트 계열(블루·민트)이 서로 다른 톤이다. 빈 상태·404 삽화로는 쓸 수 있으나 **오픈 필수가 아니다** |
| 회상 메일 발송 | 사용자 50명 넘으면 착수하기로 이미 합의됨 |
| D-2 재방문율 화면 | 데이터가 며칠치뿐이라 지금 만들면 빈 화면이다 |
| 텍스트 스타일을 OG에 적용 | 텍스트 스타일 7종이 12~28px 앱 UI용이다. OG는 1200×630 캔버스라 62·54·42px을 쓴다 — **다른 스케일임을 인정하고 문서화**한다 |

## 4. 브랜드 자산 확정 내용

Figma `97` 페이지(`Brand — Favicon` / `Brand — OG Images`)에 실물이 있다.

### 파비콘

- 바탕 `brand/symbol-bg` (= `blue/600` `#1E69CB`)
- 책 `brand/symbol-mark` (= `gray/0`)
- 북마크 `brand/accent` (= `mint/300` `#6EE7B7`) — **유일한 비(非)블루 요소**
- 아웃라인 없음. 16px에서 선 굵기 1.5는 실제 0.75px로 그려져 회색으로 뭉개지고, 그 회색이 흰 책 면적을 먹는다
- 마스터는 **512 좌표계**로 그렸다 → `app/icon.svg`에 그대로 옮긴다

### OG 3종

공통: 흰 배경(`background`) · 가운데 정렬 · 상하 최소 여백 **72px** · 배경 책장 `opacity 0.22`

| 카드 | 주인공 | 비고 |
| --- | --- | --- |
| 홈 `/` | 메인 카피 | 62px 2줄 + 서브 27px |
| 내 서재 `/[username]` | **숫자** | 권수만 58px로 키웠다. 이 카드가 하는 말이 "이 사람 157권 읽었다"이기 때문 |
| 책 기록 `/[username]/[bookId]` | **표지** | 표지 160×232. 배경 책장을 하단 90px 띠로 낮춰 제목·별점과 겹치지 않게 |

### 카피

| 자리 | 문구 | 이유 |
| --- | --- | --- |
| OG 서브 | **한 권씩 채우면, 취향이 보입니다** | 아직 안 들어온 사람이 본다 → 무슨 서비스인지 말해야 한다 |
| 기존 | ~~읽은 책이 모여 책장이 됩니다~~ | 메인 카피가 이미 "책장"을 말했다. 같은 말을 두 번 하느라 **서비스 설명 자리를 잃었다** |

⚠️ `heroSlides.ts`에 **"'당신'을 쓰지 않는다"** 규칙이 있다(밀리의서재 UI 문구 실측 기반).
배너 카피를 새로 쓸 때 이 규칙을 지킨다.

### 가운데 정렬로 바꾼 이유

일부 플랫폼이 1.91:1 카드를 **정사각으로 크롭**한다. 현행 좌측 정렬에서는
`157권`·`17권`이 안전영역 밖이라 **크롭되면 숫자가 통째로 사라진다.**

## 5. 커밋 단위

한 커밋 = 리뷰 가능한 단위로 쪼갠다.

| # | 커밋 | 범위 |
| --- | --- | --- |
| ① | 파비콘·앱 아이콘 | `app/icon.svg` 교체, `app/apple-icon.tsx` 신설, `app/manifest.ts` 신설 |
| ② | OG 공통 테마 | `shared/lib/og/theme.ts` 팔레트·상수, `CardFrame`·`BookShelf` 구조 변경 |
| ③ | OG 카드 3종 | 세 `opengraph-image.tsx` 를 새 구조로 |
| ④ | 카피 교체 | OG 서브 카피 + 배너 슬라이드 4 날짜 표현 |
| ⑤ | 미사용 이미지 정리 | `public/images/` — **삭제 전 확인받는다** |
| ⑥ | 검색·호환 메타 | `naver-site-verification`, `theme-color`, `icon.png` 폴백 |
| ⑦ | 개인정보처리방침 | 카카오 반영 — **카카오 로그인 PR에 포함** |

②③은 함께 봐야 의미가 있지만, ②만으로도 빌드가 통과하도록 나눈다.

## 6. 검증 방법

각 커밋이 실제로 먹었는지 확인하는 방법이다. **눈으로 봤다는 말로 대신하지 않는다.**

| 대상 | 명령 / 방법 |
| --- | --- |
| 파비콘·아이콘 | `curl -s -o /dev/null -w "%{http_code}" <배포URL>/apple-icon.png` → `200` |
| 메타 태그 | `curl -s <배포URL> \| grep -oE '<meta[^>]*>'` |
| OG 실물 | Preview 배포 URL을 카카오톡 나에게 보내기로 실제 전송 |
| OG 크롭 | 생성된 PNG를 정사각으로 잘라 숫자가 남는지 |
| 접근성 | 키보드 Tab만으로 로그인 → 책 기록 → 저장 완주 |
| 다크 모드 | macOS 시스템 설정 전환 후 주요 화면 순회 |

## 7. 열린 질문

- **`icon.png` 폴백을 32×32로 둘지 48×48로 둘지** — 구형 환경 대응이 목적이라 32면 충분해 보이나, 검색 결과 아이콘으로 쓰는 곳이 있어 48이 안전할 수 있다
- **미사용 이미지를 어디로 옮길지** — 저장소 밖(로컬 보관) vs `docs/` 아래(추적하되 배포 제외). `public/`이 아니면 배포에 안 실린다
