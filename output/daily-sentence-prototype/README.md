# page0127. 오늘의 문장 — 로컬 프로토타입

`index.html`을 브라우저에서 열면 됩니다. 서버·패키지 설치·로그인이 필요하지 않습니다.
HTTP 미리보기가 필요하면 저장소 루트에서 다음 명령을 실행합니다.

```sh
python3 -m http.server 4177 --bind 127.0.0.1 --directory output/daily-sentence-prototype
```

## 체험 범위

- 오늘의 문장 펼치기 → 약 3.1초 동안 자동으로 책장 넘김 → 문장 공개.
- 하루에 한 문장. 뽑은 결과를 브라우저 로컬 저장소에 보관하므로 새로고침해도 유지합니다.
- 다시 뽑기·한 줄 감상·문장별 링크 없음.
- ‘기록에 저장’ 한 번으로 날짜별 캘린더와 문장집별 기록에 함께 표시합니다. 중복 저장하지 않습니다.
- 캘린더 월 이동·이번 달 복귀·책별 기록·문장 상세·기록 삭제·다시 저장.
- 공유창에서 출처가 들어간 1080×1920 PNG 미리보기·실제 이미지 다운로드.
- Web Share API로 기기 공유창 열기. 파일 공유가 지원되지 않으면 텍스트를 공유하며, API가 없는 환경에서는 이미지 다운로드로 대체합니다.
- 문장과 출처 복사. 클립보드 권한이 없으면 직접 복사할 수 있는 선택 영역을 표시합니다.
- 모바일 레이아웃, 키보드 포커스, 모달 닫기/Escape, 모션 감소 설정 대응.

## 서비스 디자인과의 연결

기존 `packages/design-tokens/dist/tokens.css`를 변경 없이 `tokens.css`에 복사해 사용합니다. 남색 잉크·파란 CTA·흰 배경·중립 구분선을 유지하고, 책갈피에 기존 민트 포인트를 사용합니다. 앱의 Pretendard 우선 서체 스택을 사용하며 별도 외부 폰트를 불러오지 않습니다. 설치된 서체가 없으면 시스템 한글 서체로 표시됩니다.

서비스 DB·계정·실제 서재와는 연결하지 않은 독립 프로토타입입니다. 저장 데이터는 열어본 브라우저/출처에 귀속되며 HTTP 주소와 파일 주소의 저장소는 다를 수 있습니다. 브라우저 데이터 삭제 또는 저장 차단 시 유지되지 않습니다. 저장 실패는 성공으로 표시하지 않습니다. 테스트 샘플 기록을 자동으로 삽입하지 않습니다.

## 문장 콘텐츠 원칙

현재 문장 8개와 문장집 이름 3개는 이 프로토타입을 위해 새로 작성한 가상 예시입니다. 실제 책의 문장·번역문·표지를 사용하지 않았으며 화면과 공유 카드에도 예시임을 표시합니다.

정식 서비스를 위한 권장 구조:

1. 운영자가 제공하는 오늘의 문장 풀에는 이용 허락을 받았거나, 저작권 보호기간 만료 또는 적용 라이선스 조건을 개별 확인한 문장만 등록합니다.
2. 앱 내 표시뿐 아니라 이미지 생성·다운로드·공유·홍보 목적 이용 범위까지 확인합니다. 원작과 번역문, 표지 이미지의 권리는 각각 확인합니다.
3. 문장에는 실제 `bookId`, 저자, 번역자, 판본, 위치(페이지/장), 출처 URL, 권리자, 이용 근거·증빙, 만료일, 표시 허용 여부, 이미지 내보내기/공유 허용 여부를 보관합니다. 검토 전 콘텐츠는 제공하지 않는 것을 기본값으로 둡니다.
4. 기록은 `{quoteId, userId, drawnDate, savedAt}`로 한 번만 저장하고 날짜·책 기준으로 각각 조회합니다. 각 날짜나 화면마다 본문을 별도 콘텐츠로 복제해 관리할 필요는 없습니다. 분류 방식 자체가 콘텐츠 이용 허락을 대신하지는 않습니다.
5. 이용자가 직접 옮겨 적는 문장 기능은 운영자 큐레이션 풀과 분리하고 비공개를 기본으로 설계합니다. 비공개 보관도 모든 이용이 자동 허용된다는 의미는 아닙니다. 자동 공개·추천·외부 공유는 별도 검토 대상으로 둡니다.
6. 출처 표기나 짧은 길이만으로 자유 이용을 보장할 수 없습니다. 문장 자체가 주된 상품인 랜덤 뽑기를 비평·교육 목적 인용과 동일하게 전제하지 않습니다.
