# 베타 참여 안내

아래 본문은 참여 의사를 밝힌 사람에게 보내는 문안입니다. 운영자는 뒤의 확인 사항까지 읽고 사용하세요.

## 시작 안내 문안

page0127. 베타에 참여해 주셔서 감사합니다.
참여 기간은 시작일부터 2주이며, 참여비와 별도 사례비는 없습니다.

처음에는 아래 세 가지만 해 보세요.

1. [page0127.](https://page0127.com/)에서 기억나는 책 한 권을 고르거나 검색합니다.
2. 구글 또는 카카오로 가입한 뒤 그 책이 내 서재에 들어왔는지 확인합니다.
3. 그 책의 기록을 열어 평가나 한줄 생각을 남기고, 내 책장을 살펴봅니다.

책 기록은 **기본 공개**입니다. 개인적인 내용을 적기 전에 공개 설정을 확인해 주세요. 공개하고 싶지 않으면 비공개로 저장할 수 있어요. 책장 링크 공유는 선택입니다.

평가한 완독 책이 5권 이상이라면 AI 취향 분석도 해 보세요.
홈에서 책을 5권 고르는 것과 각 책에 평가를 남기는 것은 다른 단계입니다.
어디서 평가하는지 모르겠다면 그대로 알려 주세요. 분석은 필수 과제가 아닙니다.

처음 사용한 뒤 아래 두 질문에 짧게 답해 주세요.

- 무엇을 하는 서비스라고 느끼셨나요?
- 혼자 진행하기 어려웠거나 기대와 달랐던 부분이 있었나요?

인스타·카카오톡 안에서 로그인이 막히면 외부 브라우저로 열어 주세요.
고른 책이 없어지거나 저장되지 않았다면 반복 입력하기 전에 [문의](https://page0127.com/contact)로 알려 주세요.

오류를 알려 주실 때는 화면 이름·대략적인 발생 시각·기기와 브라우저·직전에 한 행동을 적어 주시면 도움이 됩니다.
비밀번호나 인증번호는 보내지 마세요. 화면을 첨부한다면 이메일과 사적인 메모는 가려 주세요.

**후속 질문 수신 여부**
이 대화에서 1주 뒤와 2주 종료 시점에 사용 경험을 묻는 짧은 연락을 받아도 괜찮으신가요?
“받을게요” 또는 “이번 후기만 남길게요” 중 편한 쪽을 알려 주세요.
선택은 자유이고, 나중에 그만 받겠다고 말씀하셔도 됩니다.

## 운영자 확인 사항

- 후속 질문은 “받을게요”라고 답한 사람에게만 보낸다. 명확한 응답이 없으면 동의로 세지 않는다.
- 참가자의 공개 서재 URL·연락 계정·후기 원문을 이 공개 저장소에 적지 않는다.
- 분석을 체험하기 위해 기억나지 않는 책이나 임의 평점을 입력하도록 권하지 않는다.
- 버튼을 대신 눌러 주기 전에 어디서 막혔는지 기록한다. 도와줬다면 “도움 없이 성공”으로 집계하지 않는다.
- 외부 브라우저 전환·가입 후 복귀 관련 수정은 다른 스레드와 담당 범위를 맞춘다.
- 오류를 발견하면 운영 기록에 남기고, GitHub 이슈에는 개인 정보와 실제 비공개 기록을 제거한 재현 절차만 옮긴다.
