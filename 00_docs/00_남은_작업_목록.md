## 지켜야 할 원칙

다른 문서·코드 주석이 이 원칙을 가리키므로 함께 둔다.

- **억지로 채우지 않는다.** 데이터가 적어 화면이 비면 빈 채로 둔다("오늘 0권 완독" 같은 문구 금지).
  할 말이 없으면 침묵한다. 지금의 병목은 기능 수가 아니라 **사용자 수**다.
- **가입 유도 실험 원칙 (2026-10-23).** ① 측정 중인 화면을 그냥 바꾸지 않는다 — 바꾸려면 A/B 로 넣는다.
  ② A/B 는 기준선 측정이 끝난 뒤 켠다(히어로 A/B 는 10/26 측정 뒤). ③ 한 화면에는 한 번에 실험 하나.
  ④ 새 실험 전에 GA 맞춤 측정기준을 먼저 등록한다(GA 는 소급하지 않는다).
- **스키마 계약.** 마이그레이션으로 컬럼을 추가하고 코드가 읽기 시작하면 `SCHEMA_CONTRACT`
  (`app/api/_helpers/schemaContract.ts`)에 한 줄 넣는다. 자동이 아니다.
- **여러 사용자를 걸치는 집계는 `is_public = true` 를 직접 건다** (SECURITY DEFINER 는 RLS 를 우회한다).
- **새 목록 링크는 `prefetch={false}`** — Vercel Hobby CPU 한도(2026-10-24 초과 대응).

      ⚠️ 책 검색 API 를 한꺼번에 수십 번 부르므로 속도 제한·실패 처리 필요.
      **캡처 이미지 인식(AI)은 2단계** — 베타 분들께 "어디서 기록을 옮겨 오는지" 물어본 뒤 정한다.
