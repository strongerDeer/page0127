# 디자인 일관성 기준 (2026-10-27)

## 점검 결과

디자인 시스템은 이미 `@repo/design-tokens` → `@repo/ui` → 앱의 3층 구조다.
색상 토큰, 공통 버튼·카드·페이지 컨테이너, Storybook, 명암비·토큰 검사가 있다.
문제는 기반의 부재보다 화면별 적용 차이였다.

| 영역 | 발견한 차이 | 이번 정리 |
| --- | --- | --- |
| 페이지 배경 | 서재·배지 페이지만 sunken | `PageContainer` 기본 배경을 background로 명시하고 두 페이지의 sunken 지정 제거 |
| 서재 프로필 | 파란 배경, 취향 카드 높이에 맞춘 중앙 정렬 | 페이지와 같은 기본 면, 왼쪽 상단 정렬 |
| 보기 전환 | 알림 사각 버튼, 서재 둥근 탭, 라운지 그림자·배틀 그라디언트 | 공통 SegmentedControl 적용 |
| 책장 보기 | 별도 높이·패딩의 토글 | 공통 SegmentedControl 적용 |
| 알림 | 유형마다 패딩·아바타·액션 배치가 다름, 차트 팔레트 사용 | 공통 행 구조·primary 아이콘·유형명·상단 정렬 |

기본 면의 `background`는 라이트 모드에서 흰색이다. 기존 OS 다크 모드 토큰은 유지한다.
회색 `sunken`은 보기 전환 바·플레이스홀더 등 보조 영역에 한정하고, 카드에는 `card`와 경계선을 쓴다.
파란 `accent`는 선택·읽지 않음·호버 상태에, `primary`와 `primary-foreground`는 선택된 탭에 쓴다.
새 색을 화면별로 만들거나 차트용 팔레트를 상태 아이콘에 쓰지 않는다.

## 저장되는 알림: 6종

| 타입 | 사용자에게 표시하는 이름 | 발생 의미 | 열었을 때 |
| --- | --- | --- | --- |
| follow | 팔로우 | 다른 독자가 나를 팔로우 | 보낸 사람 서재 |
| comment | 댓글·답글 | 내 책에 댓글 또는 내 댓글에 답글 | 해당 책 스레드 |
| like | 좋아요 | 책 기록에 좋아요 | 해당 책 스레드 |
| reading_nudge | 책 봉투 | 다른 독자가 책을 추천하거나 같이 읽자고 초대 | 책 봉투 다이얼로그 |
| reading_reminder | 독서 리마인더 | 오래 읽고 있는 책에 대한 안내 | 해당 책 |
| weekly_recap | 주간 회상 | 주간 독서 회고 안내 | 내 서재 |

댓글과 답글은 `comment` 하나에서 `target.isReply`로 문구를 구분한다.
책 추천·같이 읽기 초대도 별도 DB 유형이 아니라 `reading_nudge` 책 봉투 안의 문구다.
목록에서는 봉투 속 메시지를 미리 노출하지 않고 열기 경험을 유지한다.

## 알림을 보여 주는 형태

- 알림 페이지: 전체/읽지 않음 필터, 모두 읽음, 개별 읽음·삭제, 추가 로딩.
- 헤더 드롭다운: 같은 NotificationItem을 사용하는 축약 목록.
- 읽지 않음 배지: 헤더와 지원 환경의 앱 아이콘에 수를 표시.
- 웹 푸시: 사용자가 허용한 환경에서 전달. 책 봉투는 현재 푸시 대상에서 제외.
- 책 봉투 다이얼로그: 초대 내용을 여는 상세 경험.
- 토스트: 저장·복사·오류 등 방금 수행한 동작의 결과. 저장형 알림 6종과 별개의 일시적 피드백.
- 인라인 안내·오류·빈 상태: 해당 화면에서 해결할 내용을 그 자리에 표시.
- 확인 다이얼로그: 결정이 필요한 행동에 사용. 단순 완료 안내는 토스트로 처리.

## 공통 컴포넌트 사용

`SegmentedControl`은 기본 `role=group`, 버튼은 `aria-pressed`로 선택을 알린다.
필터와 보기 전환은 이 형태를 사용한다. 연도 선택은 기존 Select의 combobox 의미를 유지하고
`data-active`로 같은 선택 색을 적용한다.
실제 패널을 전환하는 라운지는 `tablist`/`tab`/`tabpanel`과 방향키 동작을 유지한다.

알림은 프로필(서비스 알림은 유형 아이콘), 유형명, 본문, 시각, 읽음·삭제 액션 순서다.
읽은 행은 카드 면, 읽지 않은 행은 accent 면과 점으로 구분한다. 이름과 본문은 줄바꿈하며
액션은 축소되지 않는다. 작은 화면에서는 액션을 세로로 배치한다.

## 점검 범위와 남은 경계

공통 페이지 배경과 주요 보기 전환, 서재 헤더, 알림 목록을 정리했다.
배지 삽화·책장 입체 표현·랜딩의 편집용 배너 등 도메인 시각물에는 전용 CSS가 남아 있다.
이것들을 모두 일반 카드로 바꾸는 것은 이번 변경에 포함하지 않는다.
주요 6개 로그인 페이지(서재·알림·라운지·리더 찾기·설정·배지)를 로컬 임시 계정으로 1440px·390px에서 확인했다.
모든 실데이터 조합과 운영 환경까지 검증한 것은 아니다.

Storybook에 공통 선택 컨트롤과 알림 6종, 긴 이름·답글 예시를 추가했다.
새 알림 유형은 NotificationType과 NotificationItem의 presentation 매핑을 함께 정의한다.

## 후속 공통화

- `StatePanel`: 빈 상태·영역 오류를 흰색 카드와 같은 여백으로 통일. 알림·리더 검색·피드·책장·책 상세·랭킹 오류에 적용.
- 검색 결과 사용자 카드: 흰색 면, 프로필 상단 정렬, 긴 이름 줄바꿈과 액션 축소 방지.
- 배틀 권수/쪽수/장르 전환: SegmentedControl 적용.
- 읽는 중 스트립과 라운지 독서 안내: 흰색 카드와 중립 경계선 적용.
- 배지·지난 회상 제목: PageHeader로 제목 크기와 뒤로가기 간격 통일.
- 서재 연도 선택: 데스크톱에서 선택 상자와 연도 버튼이 중복 표시되던 클래스 문자열 오류 수정.

## 검증

앱 단위 테스트 1,248개, UI 패키지 테스트 59개, 변경 영역의 Storybook 브라우저·접근성 테스트 38개 통과.
타입 검사와 변경 파일 ESLint 검사 통과. 실제 페이지에서는 흰색 배경·가로 넘침·알림 필터·서재 보기 전환을 검증했다.
로컬 DB는 최신 책 봉투 타입 마이그레이션이 없어 기본 알림 3종을 사용했다. 전체 6종 UI는 Storybook에서 확인했다.
