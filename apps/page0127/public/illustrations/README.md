# 책 봉투

`book-envelope-v2.webp`는 승인한 말 웨이터·책방·파란 봉투 시안을 바탕으로 만든 고정 일러스트다. 책
표지는 `page0127.`이라는 공통 장식이며, 실제 추천 책의 표지를 나타내지 않는다. 받는 사람·보낸
사람·메시지·책 제목은 그림에 합성하지 않고 UI에서 실제 데이터를 표시한다.

- 제작: 내장 이미지 생성 도구로 생성·편집, WebP 최적화(1200 × 900, 약 117KB).
- 최종 편집 프롬프트: 승인한 그림의 말·봉투·와인·책장과 종이 질감을 유지하고, 상단 장면만 4:3으로
  구성한다. 헤드라인·보낸 사람·버튼·하단 편지지를 제거하고 상단 왼쪽을 실제 UI 문구를 위한 빈
  공간으로 남긴다. 책 표지의 `page0127.`은 유지한다.
- 이 파일에는 사용자 이름이나 실제 독서 기록이 포함되지 않는다.

- 후속 편집: 말의 볼과 몸통 폭을 약 8~10% 줄이고, 책장 오른쪽의 ‘좋은 책은 좋은 사람을 부른다’
  표어를 복원한다. 봉투·트레이·와인·책·왼쪽 텍스트 여백과 전체 화풍은 유지한다.
- 펼친 편지지의 종이 질감은 기존 `public/badges/editorial/note-paper.webp`를 재사용한다.

## 독서 메시지 배경

- `reading-invitation.webp`: 승인된 책 추천 배경과 같은 수채화·종이 질감. 작은 말이 잠든 친구를
  살며시 깨우며 같이 읽자고 조르는 장면. 글자와 버튼은 이미지에 포함하지 않는다.
- `reading-note.webp`: 오른쪽 가장자리에서 얼굴과 앞발만 빼꼼 내다보는 말. 투명 배경. 쪽지의 상단
  오른쪽에 배치한다.
- 생성: OpenAI 이미지 생성 도구. 같은 레이아웃에서 배경만 목적에 맞게 나누며, 책 표지·메시지·보낸
  사람은 실제 데이터로 렌더링한다.
