# 배지 표지 아트

- `story-art-v3.png`: 이야기 기존 9종, 1086×1448, 3열×3행. 제목 여백 보완.
- `companion-art-v7.png`: 성장·히든 표지, 941×1672, 3열×4행. 책장·새해·세 번째 만남을 간결하게 재구성하고, 하루 두 권은 강한 타이포그래피와 두 권의 책 그래픽으로 표현한다. 완독 성장 배지 이름은 쌓이는 이야기로 변경했다.
- `expansion-art-v5.png`: 고전·방문일·분야 9종·독서 케미, 941×1672, 3열×4행. 판화·사진·회화·타이포그래피와 다양한 서체를 혼합한다.
- `companion-art-v2.png`: 사용자가 유지하기로 한 회색 공통 비밀 표지(4행 2열)의 원본.
- `note-paper.webp`: 내장 image_gen으로 제작한 투명 종이 질감. 256×256, 약 9KB. 실제 종이의 접착면·섬유·들뜬 아래쪽 그림자를 사용하며 CSS로 표지별 색을 입힌다.
- `cover-sans.woff2`: 성장 단계 숫자용 Noto Sans KR 900 서브셋. 라이선스는 `NotoSansKR-OFL.txt`.

표지의 글자·그림·여백은 완성된 아트 안에 포함한다. CSS로 그림 전체를 축소하거나 안쪽 프레임을 추가하지 않는다. 단계 숫자와 제본 색만 코드로 표시한다.

내장 image_gen으로 제작했으며 최종 편집 프롬프트는 `docs/design/badge-books/expansion-art-prompts.json`에 보관한다. 원본 PNG는 그대로 보존하고, 앱은 `sized/` 의 AVIF·WebP 사본(폭 384·480·640·800)을 `<picture>` 로 고른다. 원본을 바꾸면 `node scripts/build-badge-art.mjs` 로 사본을 다시 만들어 함께 커밋한다.
(Next 이미지 최적화로는 WebP q85 시트 한 장이 100~170KB 라 홈·프로필 이미지가 400KB 넘게 늘었다 — 2026-10-26 주간 품질 회귀.)

시트의 실제 셀 경계는 `badgeCoverArt.ts`의 crop 좌표로 지정한다. 생성된 칸의 높이가 조금 달라도 이웃 표지의 가장자리가 섞이지 않는다.
